# 瞬读 blink

数字、中文词语、英文单词连续闪现，在心里默念，自己掌控节奏。

在线使用：[瞬读默念](https://zzdloul.github.io/blink-reading/#reading) · [视线追踪](https://zzdloul.github.io/blink-reading/#tracking)

## 视线追踪

导航栏切换两种模式。切换时暂停当前练习，页面内返回后可以继续；设置和记录按模式独立保留。

- 默认「随机追踪」不断生成新的曲线和方向，不重复固定循环，不预告下一段；另外保留水平、垂直、椭圆、8 字、自由曲线五种固定路线。
- 随机路线采用连续相接的曲线，目标不会瞬移，按路程移动让速度保持平稳；速度始终由用户手动控制。
- 默认不限时；速度 0.3–2.5 倍、圆点 6–64 px、三档范围和可关闭的轨迹线。
- 「跟丢了」停住目标并记一次自报，重新看住后继续；恢复前倒计时，缓慢起步。
- 目标尺寸和速度训练中生效；换路线、范围、画面尺寸时先暂停重新定位。后台或超过 500 ms 的画面中断会暂停，避免跳过轨迹。
- 手机专注模式内调节圆点大小，L 键报告跟丢，其余快捷键同瞬读。
- 记录实际播放时长、自报跟丢次数和自评；不检测真实眼动，不声称准确率或保证能力提升，不用于医疗视力治疗。

## 使用

- 默认混合、不限时：不点击「休息一下」或「结束本轮」，就会持续训练。
- 闪现时间与默念间隔分别支持 100–2000 ms；提速 / 减速每次各调整 50 ms。
- 文字大小可用滑块或输入框调到 **6–200 px**，训练中立即生效。长内容在小屏幕上会自动缩小以避免溢出。
- 三种长度，可选 1 / 2 / 5 分钟；默认不限时。
- 自定义词库：2–500 个不同内容，每个最多 24 字。
- 专注模式、空格休息 / 继续、↑↓ 调速、F 专注、Esc 休息并退出专注。
- 切出页面或锁屏后自动休息，不把后台时间计入训练。
- 结束时记录实际练习时长、已呈现数量与自我感受；数量不代表识别准确率。
- 设置和最近 100 轮记录仅保存在当前浏览器。无登录、无广告、无分析追踪、无后台；不同设备不自动同步。

## 本地开发

需要 Node.js 20+，没有第三方依赖。

```sh
npm start
npm test
npm run check
```

打开 http://127.0.0.1:4173 。浏览器需支持 ES modules 和原生 dialog。

## 发布

本项目是静态网站，GitHub Pages 发布源为 `main` 分支根目录。`.nojekyll` 保留原始文件。所有资源使用相对路径，支持项目子目录。

## 实现

- `engine.js`：按浏览器帧驱动的训练时钟、暂停、时长与速度边界。
- `content.js`：词库、均衡混合、去相邻重复、自定义输入校验。
- `storage.js`：有界、可失败的本地保存与读取校验。
- `app.js`：交互、响应式字号、对话框与记录。
- `shell.js`：导航、直达链接与模式切换时的暂停协调。
- `tracking-engine.js`：有边界的闭环轨迹、平滑变速、暂停恢复和输入校验。
- `tracking.js` / `tracking.css`：追踪界面、专注布局与独立记录。
- `tests/engine.test.mjs`：计时、无限时、暂停、内容与数据边界测试。
- `tests/tracking.test.mjs`：轨迹连续性和边界、速度/计时/恢复、记录验证。

文字直接显示 / 隐藏，不做淡入淡出，不闪动背景。显示时间受刷新率与设备性能影响，设置值不是实验仪器的精密计时。自评仅用于决定下一轮节奏，本工具不会推断认知能力或承诺训练收益。
