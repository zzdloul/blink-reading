  1. 从舒服的节奏开始

    先试 600 ms 闪现 + 400 ms 间隔。默认不限时，一直练到你点「休息一下」。休息后可以继续，也可以结束本轮。

  2. 让留白成为默念的时间

    “闪现时间”是文字在屏幕上停留的时间；“默念间隔”是文字消失后的空白时间，两者共同决定节奏。

  3. 把文字调到适合你的大小

    字号可在 6–200 px 之间调节，也可以直接输入数字。正在训练时立即生效。长内容超出屏幕时会自动缩小。

  4. 跟得上，再小幅提速

    连续一小段都能读清时，点一次“提速”；常常来不及，就减速或缩短内容。每次提速会各减少 50 ms。

  5. 在结束后回想一下

    试着回想最后几个内容，再记录“轻松 / 刚好 / 吃力”。不追求只刷数量；累了就休息。

混合与长度　混合模式轮流打乱数字、中文和英文。轻松：2位数字、2字常用词、2–4字母；标准：4位、2字、5–7字母；挑战：6位、4字、8字母以上。

手机使用　点击训练框右下角进入专注模式。可用手机浏览器的分享或菜单功能将网页添加到主屏幕；训练记录保存在该浏览器。

键盘　空格休息 / 继续，↑ 提速，↓ 减速，F 进入 / 退出专注，Esc 休息并退出专注。

自动休息　切到其他页面或锁屏时自动休息，回来后手动继续。

关于记录　时长、已呈现数量和自评只存在当前浏览器，不会上传；不同设备不会同步。呈现数量不代表正确率或记忆能力提升。本工具无法判断你是否完成了默念。

小提示　实际显示精度受屏幕刷新率和设备性能影响。保持舒适的屏幕亮度，不适时停止。
