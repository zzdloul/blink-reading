先读清，再提速。

眼睛看见，在心里轻轻读出。不用出声，也不用抢答。

  1. 从舒服的节奏开始

    先试 600 ms 闪现 + 400 ms 间隔。默认不限时，一直练到你点「休息一下」。休息后可以继续，也可以结束本轮。

  2. 留意不同位置

    每个新内容会随机出现在训练区域内，显示期间保持不动。文字会避开边缘与底部按钮，休息后继续显示同一内容时保留原来的位置。

  3. 让留白成为默念的时间

    “闪现时间”是文字在屏幕上停留的时间；“默念间隔”是文字消失后的空白时间，两者共同决定节奏。

  4. 把文字调到适合你的大小

    字号可在 6–200 px 之间调节，也可以直接输入数字。正在训练时立即生效。长内容超出屏幕时会自动缩小。

  5. 跟得上，再小幅提速

    连续一小段都能读清时，点一次“提速”；常常来不及，就减速或缩短内容。每次提速会各减少 50 ms。

  6. 在结束后回想一下

    试着回想最后几个内容，再记录“轻松 / 刚好 / 吃力”。不追求只刷数量；累了就休息。

混合与长度　混合模式轮流打乱数字、中文和英文。轻松：2位数字、2字常用词、2–4字母；标准：4位、2字、5–7字母；挑战：6位、4字、8字母以上。

手机使用　点击训练框右下角进入专注模式。可用手机浏览器的分享或菜单功能将网页添加到主屏幕；训练记录保存在该浏览器。

键盘　空格休息 / 继续，↑ 提速，↓ 减速，F 进入 / 退出专注，Esc 休息并退出专注。

自动休息　切到其他页面或锁屏时自动休息，回来后手动继续。

关于记录　时长、已呈现数量和自评只存在当前浏览器，不会上传；不同设备不会同步。呈现数量不代表正确率或记忆能力提升。本工具无法判断你是否完成了默念。

小提示　实际显示精度受屏幕刷新率和设备性能影响。保持舒适的屏幕亮度，不适时停止。

先跟稳，再加一点难度。

这是用目光跟随移动目标的自主练习。不需要触摸圆点，也不会调用摄像头。

  1. 看住圆点，平稳跟随

    保持舒适坐姿和观看距离，自然眨眼，不用憋着不眨眼。开始前有倒计时，圆点会慢慢起步。

  2. 选择随机或固定路线

    随机追踪不断生成新的弯曲和方向，不提前显示未来轨迹。固定路线适合先熟悉跟随。速度可随时手动调节，开始时可以慢一些。

  3. 跟丢时，停下来重新找到

    点「跟丢了」会停住目标并记录一次自报。看清圆点后，可先减速，再点「重新跟上」。

  4. 把练习感受留下来

    两种模式有各自的本机记录。这里只记录播放时长、你主动报告的跟丢次数与自评，不会把“没有点击跟丢”认定为始终跟上。

操作　空格休息 / 继续，↑↓ 调速，L 报告跟丢，F 专注，Esc 休息并退出专注。切换模式、切到后台或画面明显卡顿时会暂停。手机旋转或改变练习区域大小时，也会先暂停重新定位。

练习边界　不保证练出持续追踪能力，也不用于治疗视力问题。出现眼酸、头晕、复视等不适时停止；有持续不适或已知眼部问题时，向眼科专业人员咨询。阅读 AAPOS 关于视觉训练的说明。
